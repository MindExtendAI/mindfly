The [asset notices](../public/ATTRIBUTION.txt) record component sources and licenses.

**Reading the scientific claims:** MaleCNS supplies recorded anatomy and connectivity.
Neural firing and movement are simulated. Neither the animation nor the software
reference checks establish an exact reproduction of the Bidaye experiment.
